# Runbook — Phase 2a

**Nothing here yet. Phase 2a is designed (`docs/design/phase-2a.md`) and not built.**

This file exists so the design doc's references to it resolve, and so there is one
obvious place for the evidence when there is any. Until then, every Phase 2a
claim is unproven, and that is the correct thing to say about it.

What has to appear here before 2a can be called done — from design §1.3 and §11:

- [ ] A real approval **denied** by tapping Deny in the Telegram group.
- [ ] A real approval **expired** unanswered, with the default-deny recorded.
- [ ] A real approval **granted**, performing a real write to `wiki/`.
- [ ] A button pressed by a non-owner, refused and recorded as a security event.
- [ ] A class grant short-circuiting a librarian pass, and expiring.
- [ ] Approvals still working with the window exhausted (sentinel mode).
- [ ] A real voice note becoming an inbox entry.
- [ ] A 07:00 morning brief Chris judges useful.
