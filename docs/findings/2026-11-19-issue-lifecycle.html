aleph factory · issue lifecycle

Every failure on the way to main has one fixed place to go

A failed check or a reviewer hold goes back to the worker for at most 2 fix rounds. What is left goes to the rescue once, then to an Ask that the director tries before Chris.

1. Intake: one model run turns a request into a spec

2. Dispatch: ten gates, first one that binds wins

3. Worker, verify and review: fix rounds before anything else

4. Land: one at a time per repo, retries before rescue

5. Rescue and Asks: the director answers before Chris
