A. In the box: a trailing hint

Recommended. The hint sits inside the search box at its right end, so nothing moves. Enter files. The hint is a button, so a click files too. It shows only while the box has text.
  • Zero shift: the box keeps its size.
  • Discoverable only once you type. The placeholder can say it: “Search, or type a title to file”.
  • Long queries run under the hint: the input gets right padding the width of the hint.
