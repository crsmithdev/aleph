UI Re-think

7 pages

What Is Wrong

  1. One template for every page. docs/design.md says "page head, metric cards, then cards". A browser, an analysis, a settings page and an inventory all open with 5 or 6 metric cards and 3 or 4 charts. The page's own content starts below the first screen.
  2. Pages mix kinds. Automation holds settings, evidence, the monitor and an audit log. Jobs holds a timing analysis and a job browser. Sessions holds tool analysis, a session browser and two hook tables. Page heights at 1440 px: Automation 4238 px, Hooks 4162 px, Jobs 3131 px, Sessions 3108 px, Issues 2474 px, Memory Notes 15807 px.
  3. Equal visual weight. Each block is the same white card. A problem is quiet: the OpenRouter 402 error is one line of muted text, and the 151 hook errors are one tile of five.
  4. Tables print defaults. medium, done, aleph, 0 and 0d fill the Issues table of 11 columns. Jobs repeats a title 3 or 4 times for one issue. Hooks shows a meter and the same 6 numbers beside it.
  5. Controls are heavy and scattered. Automation has 10 Save buttons. Each chart has a toggle of 5 buttons. The 5 dock buttons float over table columns.
